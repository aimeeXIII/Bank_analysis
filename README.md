# Banking Analyzer

Приложение для анализа банковских операций из Excel-файла.

## Возможности
- **Веб-страницы** (`views.py`): Главная (приветствие, карты, топ-5, курсы валют и акций) и События (расходы/поступления по периодам W/M/Y/ALL).
- **Сервисы** (`services.py`): анализ категорий кешбэка, Инвесткопилка, простой поиск, поиск по телефонам и переводам физлицам (regex).
- **Отчёты** (`reports.py`): траты по категории / дням недели / рабочий-выходной. Декоратор `@report_to_file` сохраняет результат в JSON.
